# Modulus

> AI/Agent observability and telemetry platform for monitoring agent executions, tool calls, traces, and events.

Modulus is a full-stack observability platform designed for AI agents and agentic applications. It provides a structured way to collect, normalize, redact, store, and visualize telemetry generated by AI agents and their tool calls.

The project is built as a TypeScript monorepo using **npm Workspaces** and **Turborepo**.

---

## ✨ Features

- 🔭 AI agent execution observability
- 📊 Execution and trace tracking
- 🛠️ Tool-call monitoring
- 🔐 Sensitive-data redaction
- 📦 OpenTelemetry-inspired ingestion
- ⚡ Asynchronous ingestion using BullMQ
- 🗄️ PostgreSQL persistence through Prisma
- 🔑 API-key and session-based authentication
- 👥 Organization and role-based access control
- 📡 TypeScript SDK for instrumenting AI applications
- 🧩 Modular monorepo architecture
- 🚀 Turborepo-powered builds and development
- 🌐 Full-stack web dashboard
